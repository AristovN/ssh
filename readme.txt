Эта программа позволяет без участия администратора выполнять одну последовательность bash команд на Linux серверах на множестве хостов.

Ограничения:
1. Не работает команда su (открывается новый tty, не ясно как к нему присоединяться)
2. Отправка по sftp не поддерживает отправку каталогов. Если нужны будут каталоги, то их необходимо будет заархивировать.
+ файлы по sftp передаются поодиночке.

Алгоритм работы программы:
1. Логин для подключения считывается из файла user.txt
2. Пароль для подключения считывается из файла password.txt
3. Считывается файл hosts.txt, берется список хостов
4. Проход циклом по всем хостам, для каждого хоста создается текстовый лог-файл в папке log результами выполнения команд
5. Проверка доступности хоста
6. Выполняется подключение к хосту по ssh
7. На хост загружаются файлы из папки files по sftp в каталог ~/sftp_files . Все файлы в папке делаются исполняемыми
8. На хосте выполняется список команд из файла commands.txt, результаты выполнения сохраняются в лог-файле
9. С хоста удаляется каталог ~/sftp_files
10. Закрывается лог-файл, закрывается подключение к хосту
11. Повтор с пункта 5 для следующего хоста
